# Openpath brand files

The mark is a shield around a payment's route: a node at each end and a check between them. Every payment is checked before it moves.

| File | Use |
|---|---|
| `openpath-mark.svg` / `.png` | The mark on its own, transparent background (favicon source) |
| `openpath-profile.svg` / `.png` | 1024 px square, full bleed, for profile pictures on X, YouTube and GitHub (round crops stay clean) |
| `openpath-logo-light.png` | Logo with the name, transparent background, for light backgrounds |
| `openpath-logo-dark.png` | Logo with the name, transparent background, for dark backgrounds |

Colors: indigo `#4338ca`, soft indigo `#a5b4fc`, ink `#0f1729`. Typeface: Inter, extra bold.
